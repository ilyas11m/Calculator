# Java Swing Calculator

Простой калькулятор, реализованный на Java с использованием библиотеки Swing для создания графического интерфейса пользователя.

## О проекте

Данный проект представляет собой настольное приложение-калькулятор, поддерживающее базовые арифметические операции:

- Сложение
- Вычитание
- Умножение
- Деление

Графический интерфейс построен с помощью стандартной библиотеки Java Swing.

## Интерфейс

Приложение имеет простую форму, аналогичную встроенному калькулятору Windows

## Технологии

- Java SE
- Swing (javax.swing)
- IDE: IntelliJ IDEA
